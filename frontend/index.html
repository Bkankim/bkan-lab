숫자는 어떻게 셌나

딸깍
제가 AI에게 직접 보낸 메시지 수입니다. 작업 완료 알림 같은 자동 메시지는 빼고, 1분 안에 거의 같은 문장을 고쳐 다시 보낸 것은 한 번으로 셉니다. 교정은 그중 AI가 기대와 다르게 만든 것을 바로잡은 메시지입니다.
AI 작업
AI(본체와 서브에이전트)가 실제로 일한 시간입니다. 여럿이 동시에 일한 시간은 한 번만 셉니다. 10분 넘게 아무 기록이 없던 시간과 제 승인을 기다린 시간은 뺐습니다.
API 정가 환산
쓴 토큰을 Anthropic API 정가(캐시 쓰기·읽기 단가 포함)로 계산한 값입니다. 실제로는 정액 구독으로 썼습니다. 브라우저 에이전트(aside) 안에서 쓴 토큰은 기록이 없어 빠져 있습니다.
서브에이전트
본체 AI가 일을 나눠 맡긴 하위 AI의 수입니다.
